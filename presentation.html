Abstract

VoxForensics is an advanced AI-powered web application designed to detect deepfake audio content in real-time. With the rapid advancement of AI voice cloning technologies, distinguishing between authentic human voices and AI-generated synthetic audio has become increasingly challenging.

Our system employs sophisticated acoustic feature extraction and machine learning algorithms to analyze voice recordings and classify them as either real or AI-generated with high accuracy (85-98% confidence).

Working Mechanism

Step 1: Audio Input & Preprocessing

Recording/Upload

  • Real-time microphone capture using Web Audio API
  • File upload with drag-and-drop support
  • Security validation (file type, size, integrity)
  • Audio normalization and preprocessing

Supported Formats

.wav .mp3 .m4a .flac .ogg

Maximum file size: 25 MB

Step 2: Feature Extraction

The system extracts 10 key acoustic features from the audio signal using advanced signal processing techniques:

1. Pitch Variability

Measures natural pitch fluctuations

2. Formant Stability

Analyzes vocal tract resonance patterns

3. Spectral Flatness

Detects vocoder artifacts

4. Harmonic Ratio

Measures harmonic content quality

Working Mechanism (Cont.)

Acoustic Features Analyzed

Feature Real Voice AI Voice
Pitch Variability 0.18-0.60 0.02-0.12
Formant Stability 0.45-0.85 0.88-0.99
Spectral Flatness 0.01-0.08 0.08-0.20
Harmonic Ratio 0.65-0.95 0.40-0.68
Temporal Modulation 0.35-0.95 0.15-0.40

Additional Features:

  • Zero Crossing Rate
  • Spectral Centroid
  • Spectral Rolloff
  • MFCC Energy
  • Chroma Features

Step 3: AI Classification

Multi-factor scoring algorithm analyzes all features, applies weighted thresholds, and calculates confidence scores. Cross-feature consistency check ensures robust detection even with noisy recordings.
